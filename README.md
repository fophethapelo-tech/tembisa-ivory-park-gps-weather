# Tembisa & Ivory Park GPS Weather — FINAL RELEASE

This is the final Progressive Web App (PWA) package.

Features:
- GPS and local weather
- Tembisa sections and Ivory Park extensions/areas
- Surrounding Ebony Park, Rabie Ridge, Clayville and other areas
- Street and satellite maps
- Taxi, Personal Car, Delivery, Bolt and Pedestrian modes
- Live GPS route monitoring
- Voice commands
- Nearby schools, churches, clinics and other places
- Settings
- Chrome installation / Add to Home screen support

## Publishing requirement
Upload ALL files in this folder to the same GitHub repository and publish the repository with GitHub Pages (or another HTTPS host). PWA installation requires the website to be served securely over HTTPS (localhost is an exception for local testing).

After the live HTTPS website is open in Chrome, eligible users will see Chrome's Install app / Add to Home screen option.
