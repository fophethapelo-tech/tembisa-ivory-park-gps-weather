# Tembisa & Ivory Park GPS Weather

A mobile-first local weather and GPS web app for Tembisa, Ivory Park and surrounding communities.

Features:
- GPS location and browser permission handling
- Local weather and 7-day forecast using Open-Meteo
- Tembisa sections and Ivory Park areas
- Driver mode for taxi, private car, delivery and Bolt/ride-hailing
- Route display and moving vehicle marker
- Nearby schools, churches/places of worship, clinics, police stations, petrol stations and shops using OpenStreetMap data
- Installable as a PWA from Chrome after publishing on HTTPS
