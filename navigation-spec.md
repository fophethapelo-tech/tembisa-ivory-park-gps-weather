# Nationwide Navigation Final Specification

- Nationwide South Africa coverage: all 9 provinces.
- Residential address search: house number + street + suburb + city/province; landmark and POI search.
- Live GPS: high accuracy, continuous position updates, road snapping/map matching, follow camera, off-route detection and recalculation.
- Start/end: clearly show current starting point and selected ending point.
- Moving marker: car for driving, pedestrian for walking, visibly following the road/path.
- Road awareness: turns, intersections, traffic signals, stop signs, roundabouts, pedestrian crossings, motorway/freeway/highway entries/exits, toll facilities, road works and mapped hazards where supported by map data.
- Live traffic: only claim live congestion when a real-time traffic data provider is connected; otherwise distinguish mapped road information from live traffic.
- Voice: automatic safety warning first; then concise turn-by-turn guidance. Speak only for safety warnings, upcoming turns, route changes, significant road warnings, off-route/recalculation and arrival. Avoid repeating the same instruction. Distance thresholds should progressively announce important turns (for example ~500m, ~200m, ~80m) only when useful and only once per threshold.
- Name profiles: input a driver/pedestrian name and Save; maintain a saved list of multiple names in local storage; allow selecting a saved name for navigation; selected name is used naturally in voice prompts.
- Existing weather, Power Outage, Load Shedding and other working features must remain intact.
